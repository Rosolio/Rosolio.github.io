# leetcode hot100 刷题小记

## 1. 哈希表
哈希表的遍历
```c++
for (auto it = mp.begin(); it != mp.end(); ++it) { // 迭代器
            ans.emplace_back(it->second); // emplace_back 比 push_back 更快
        }
```
集合 -> 去重
```c++
unordered_set<int> s(nums.begin(), nums.end()); // 集合记录数组元素，去重
s.count(x); // exist
s.insert(x);
s.erase(x);
```
